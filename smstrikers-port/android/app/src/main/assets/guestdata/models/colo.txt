# Colosseum Pokemon on the guest roster -> GPK2 (tools/outside/colo_guests.py -> colopack.py -> meleepack.py
# --model-space-env --subdivide 1 [--matanim] --height --map colo-bone-map.json --ground, then
# colo_resize_finish.py's fixes; shiny: colo_shiny.py). Our tuning only, no game data.
#   pack <pack> <pkx name>       the model archive pkx_<name>.fsys
#   height_m / game_height       Pokedex height (m) / our size override (m)
#   hover / gas_color / gas_opacity / yaw / class / flap_l / flap_r / map: colo-bone-map.json
#   shiny rare | map             Colosseum's own shiny model (pkx_rare_<name>) or our colour map
#   flame <joint> <size>         the Charmander line's tail fire (colo_flame.py)
#   drop <packet>                a packet left out (gpk_drop.py: Weezing's helper boxes)
#   retex <data offset>          that texture record made again from its picture as it is
#                                (Sceptile: its gas card's recolour had taken the shared picture)
#   upright <x+90|z+90..>        a model lying in its file stood up (meleepack --upright; r130 Slaking)
#   skin <joint> <mode>          a DObj owner's skin mode forced (r130 Flaaffy's face: 50 owner)
#   repose <op> ...              gpk_repose.py on the built pack (r130 Slaking: unlean / mirror)
#   rebind flat <deg> <node> ..  gpk_rebind.py --flat on the built pack (r130 Vigoroth's feet)
#   fix hariyama                 hariyama_fix.py on the built pack (r130: knees + leg weights)
#   reparent <node>:<parent> ..  gpk_reparent.py on the built pack (r127 Aggron's feet, r130 ...)
#   stand vaporeon               r130: vap_stand.py (re-posed standing bind) + vap_applymap.py with
#                                the map below (vaporeon.json), not the plain build
#   scale_show / scale_hide <j>  r135: meleepack --scale-show / --scale-hide (Swellow's wings)
#   env_not_card                 r135: meleepack --env-not-card (Wailmer's body stays mesh)
#   post <step> <args>           r135: a post-build step, in the PC's order (Models.post: reparent,
#                                repose (+ pitch / turn), standbind, fix135, pivot, drop, fish)
#   tex_square                   r145: the pictures' colours squared (gpk_texsquare.py: Porygon), on the
#                                pack and its shiny after the shiny is made
#   (order on the headset as on the PC: build, drop, repose / rebind / fix, reparent, post ...; shiny
#   from it)
